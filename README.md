تولیدکننده پایگاه داده هیوریستیک برای 8 پازل (8-Puzzle)

این پروژه یک برنامه نوشته‌شده با زبان ++C است که برای پازل ۳×۳ (8-Puzzle)، یک پایگاه داده هیوریستیک کامل تولید می‌کند.

برنامه با استفاده از الگوریتم Breadth-First Search (BFS) از حالت هدف شروع کرده و تمام حالت‌های قابل دستیابی را تولید می‌کند، سپس فاصله دقیق هر حالت تا حالت هدف را در فایل heuristic.txt ذخیره می‌کند.

همچنین برنامه از مفهوم Star Tiles (*) برای ساخت Pattern Database و انتزاع حالت‌ها پشتیبانی می‌کند.

قابلیت‌ها
تولید تمام حالت‌های قابل دستیابی در پازل ۳×۳
محاسبه فاصله دقیق تا حالت هدف
ذخیره پایگاه داده هیوریستیک در فایل متنی
بارگذاری سریع پایگاه داده
تست حالت‌های مختلف پازل
پشتیبانی از خانه‌های ستاره‌دار (*)
استفاده از BFS برای تضمین کوتاه‌ترین فاصله
نحوه کار برنامه
1. دریافت حالت هدف (Goal State)

ابتدا کاربر وضعیت نهایی پازل را وارد می‌کند.

مثال:

1 2 3
4 5 6
7 8 0

عدد 0 نشان‌دهنده خانه خالی است.

2. تعریف خانه‌های ستاره‌ای (*)

برنامه اجازه می‌دهد بعضی اعداد به‌عنوان Star تعریف شوند.

مثال:

How many stars (*) ? 2
Enter star values:
1 2

در این حالت، اعداد 1 و 2 هنگام ذخیره‌سازی وضعیت‌ها به شکل * نمایش داده می‌شوند.

نمونه نمایش:

*,*,3,4,5,6,7,8,0,

این قابلیت برای موارد زیر مفید است:

ساخت Pattern Database
کاهش فضای حالت
طراحی هیوریستیک‌های پیشرفته
3. تولید تمام حالت‌ها با BFS

برنامه از الگوریتم BFS استفاده می‌کند تا:

تمام حالت‌های قابل دستیابی را پیدا کند
فاصله دقیق هر حالت تا هدف را محاسبه کند
اطلاعات را داخل فایل ذخیره کند

چون BFS به‌صورت سطح‌به‌سطح عمل می‌کند، اولین باری که یک حالت دیده می‌شود کوتاه‌ترین مسیر به آن حالت است.

فایل پایگاه داده هیوریستیک

تمام حالت‌ها در فایل زیر ذخیره می‌شوند:

heuristic.txt

فرمت هر خط:

state_string distance

مثال:

1,2,3,4,5,6,7,8,0, 0
1,2,3,4,5,0,7,8,6, 1

عدد دوم نشان‌دهنده فاصله دقیق تا حالت هدف است.

تست هیوریستیک

بعد از ساخت دیتابیس، کاربر می‌تواند هر وضعیت دلخواهی را تست کند.

نمونه خروجی:

Exact Distance To Goal = 12

اگر حالت وارد شده قابل دستیابی نباشد:

This state is NOT reachable from the goal state.
الگوریتم استفاده‌شده
Breadth-First Search (BFS)

این پروژه از BFS برای موارد زیر استفاده می‌کند:

پیمایش فضای حالت‌ها
تضمین کوتاه‌ترین مسیر
تولید هیوریستیک دقیق
ساختمان داده‌های استفاده‌شده
queue<State> → برای BFS
unordered_set<string> → جلوگیری از تکرار حالت‌ها
unordered_map<string,int> → ذخیره هیوریستیک
vector<vector<int>> → نمایش صفحه پازل
